---
title: Create an API Account
---
Before you can make your first request, you need a WAV API Account.

1. Head to [wav.com/api](https://wav.com/api) and click on **Get started** or select one of the available API Packages:

2. Enter your payment information.

3. 🎉 Congratulations! You now have a WAV API Account and are ready to start making requests.

4. Check out [API Dashboard](https://wav.com/api-dashboard) - get your API Keys and start generating.
