---
title: Keys to the Castle 
---

To make requests to the wav API, you need to create an API Key 🔑

Head to your [API Dashboard](https://wav.com/api-dashboard) and click on API Keys.

If you don't have a key, click on Create key, give it a name, and click Create API Key.

Click on the Eye Symbol 👀 next to your key to reveal it.

🎉 Congratulations! You’ve gained access.
