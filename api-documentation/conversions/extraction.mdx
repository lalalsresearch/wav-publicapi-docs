Extract vocals, instrumentals, or other stems from an audio file or URL, with optional preprocessing. 

---
## Endpoint

```http
POST /v2/Extraction
```

Use this endpoint to extract stems like vocals, drums, guitar, or more from an audio source.

---

## Request Parameters

| Parameter               | Type         | Required | Description                                                                                 |
| ----------------------- | ------------ | -------- | ------------------------------------------------------------------------------------------- |
| `audio_url`             | `string`     | Optional | URL of the audio file to extract from. Either `audio_url` or `audio_file` must be provided. |
| `audio_file`            | `File` | Optional | Audio file to upload and process. Either `audio_url` or `audio_file` must be provided.      |
| `stem_preset`           | `string`     | Optional | Quick preset instead of `stems`: `2_stems` or `6_stems`. See [Stem presets](#stem-presets). Free on paid plans in November 2026. |
| `stems`                 | `string`     | Optional | JSON string list of required stems. e.g., `["vocals", "drums"]`. Required unless you send `stem_preset`. See all options below. |
| `preprocessing_options` | `string`     | Optional | JSON string list of preprocessing options. e.g., `["Denoise"]`. See all options below.      |
| `eco_mode`              | `boolean`    | Optional | Enable eco mode for faster parallel extraction. Default: `false`. |
| `webhook_url`           | `string`     | Optional | Callback URL to receive async processing results.                                           |

> **Max input audio length:** 8 minutes. See [Audio Length Limits](/api-documentation/utilities/ratelimits#audio-length-limits).

>**Note:** Either `audio_file` or `audio_url` must be provided, and either `stems` or `stem_preset`, not both.

>**content-type:** multipart/form-data

---

## Stem presets

Use `stem_preset` to request a common split without listing stems. The preset replaces `stems`, so leave `stems` out or send `[]`.

| `stem_preset` | Stems you get back | Good for |
| ------------- | ------------------ | -------- |
| `2_stems` | `vocals`, `instrumental` | Karaoke tracks, acapellas, vocal remixes |
| `6_stems` | `vocals`, `instrumental`, `piano`, `bass`, `drums`, `guitar` | Full band breakdowns, practice tracks, sampling |

You can combine a preset with `preprocessing_options` and `eco_mode`. The webhook returns one URL per stem, exactly as a `stems` request does.

<Tip>
  **Free in November 2026.** From Nov 1 00:00 to Nov 30 23:59:59 UTC, preset requests from paid plans are free, up to **10 per clock hour** and **100 per day** (UTC). The response tells you whether a request was free and how many free requests you have left. See the [free stem presets guide](/api-documentation/conversions/extraction-free-stems-guide) to get the most out of it.
</Tip>

## Available Stems

The following audio stems can be extracted. They are grouped into categories based on instrument type or function:

### Vocals

- `vocals` — All vocal content (combined)
- `male_vocal` — Male vocals only
- `female_vocal` — Female vocals only
- `lead_vocal` — Lead singer’s voice
- `back_vocal` — Backing vocals

### Guitar

- `guitar` — All guitar sounds
- `acoustic_guitar` — Acoustic guitar
- `electric_guitar` — Electric guitar
- `rhythm_guitar` — Rhythm guitar parts
- `solo_guitar` — Solo guitar parts

### Drums

- `drums` — All drum elements
- `kick_drum` — Kick or bass drum
- `snare_drum` — Snare drum
- `toms` — Tom drums
- `hi_hat` — Hi-hat cymbals
- `ride` — Ride cymbal
- `crash` — Crash cymbal

### Keys and Piano

- `piano` — Piano only
- `keys` — Keyboard instruments (includes synths, organs, etc.)

### Strings and Winds

- `strings` — String instruments (e.g., violin, cello)
- `winds` — Wind instruments (e.g., saxophone, flute)

### Other Instruments

- `bass` — Bassline instruments
- `instrumental` — All non-vocal content (used to get instrumental version)

### Full Band (Composite)

- `drums`, `bass`, `piano`, `guitar` — Common full-band instrumentation

> **Note:** Without a `stem_preset`, `stems` must contain at least one stem. An omitted or empty `stems` list returns `422`.

## Preprocessing Options

These preprocessing steps can be applied to the input audio before stem extraction:

- `Denoise` — Reduces ambient or background noise
- `Deecho` — Removes echo and early reflections
- `Dereverb` — Reduces late reverberation from recordings

## Sample Request

### cURL with a stem preset

Free on paid plans during November 2026.

```bash
curl -X POST "https://api.wav.com/api/public/v2/Extraction" \
-H "accept: application/json" \
-H "Authorization: <api_key>" \
-F "audio_url=<YOUR_AUDIO_URL>" \
-F "stem_preset=6_stems" \
-F "webhook_url=https://example.com/webhook"
```

### cURL with a stems list

```bash
curl -X POST "https://api.wav.com/api/public/v2/Extraction" \
-H "accept: application/json" \
-H "Authorization: <api_key>" \
-F "audio_file=@path_to_audio.mp3" \
-F "stems=[\"vocals\",\"drums\"]" \
-F "preprocessing_options=[\"Denoise\"]" \
-F "webhook_url=https://example.com/webhook"
```

### Python

```python
import requests
import json

url = "https://api.wav.com/api/public/v2/Extraction"

headers = {
    "Authorization": "<API_KEY>"
}

data = {
    "stems": json.dumps(["vocals", "drums"]),
    # Or use a preset instead of "stems" (free on paid plans in November 2026):
    # "stem_preset": "2_stems",
    "preprocessing_options": json.dumps(["Denoise"]),
    "eco_mode": False,
    "webhook_url": "https://example.com/my-webhook"
}

# Option 1: audio_url
data["audio_url"] = "<YOUR_AUDIO_URL>"
response = requests.post(url, headers=headers, data=data)

# Option 2: File Upload
# with open("song.mp3", "rb") as f:
#     files = {"audio_file": f}
#     response = requests.post(url, headers=headers, data=data, files=files)

print(response.json())
```

## Common Errors

* **402 Payment Required** (`INSUFFICIENT_CREDITS`): Your credit balance is insufficient for a charged request.
* **422 Unprocessable Entity** (`UNPROCESSABLE_CONTENT`): Neither `audio_url` nor `audio_file` is provided, `stems` is empty without a `stem_preset`, `stem_preset` is not `2_stems` or `6_stems`, or both `stems` and `stem_preset` are sent.
* **500 Internal Server Error** (`INTERNAL_SERVER_ERROR`): A server-side error occurred.

See [Handling Errors](/api-documentation/utilities/error) for the error response format and all error codes.
